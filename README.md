# 🎬 Netflix Clone

A responsive **Netflix landing page clone** built using **HTML and CSS** as a frontend practice project during my first year of college. The project focuses on responsive design and recreating Netflix's modern user interface.

## 🚀 Live Demo

🔗 **(https://netflix-clone-chi-teal.vercel.app/)**

## ✨ Features

* 📱 Fully responsive design
* 🎬 Netflix-inspired UI
* 🎨 Built with HTML5 & CSS3
* ⚡ Clean and modern layout

* HTML5
* CSS3
